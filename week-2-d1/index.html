box model

if you have set the background color of an element, you may have noticed that the color was applied not only to the area directly behind the element but also to the area to the right of the element.

Also, if you have aligned text, you know it is aligned relative to something. What is that something?

The box model contains the set of properties that define parts of an element that take up space on a web page.

  • the content area’s size (width and height)
  • margin
  • padding
